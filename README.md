> **Идея в одной строке:** пользователь вводит тему или загружает PDF/BibTeX, а получает сравнительную матрицу статей, которой можно доверять (у каждой строки реальный кликабельный DOI и пометки «не указано» вместо галлюцинаций), интерактивный научный диалог и готовый к компиляции `.bib` / LaTeX пакет для Overleaf.

**TensorText** — это интеллектуальное академическое рабочее пространство для магистрантов, аспирантов и исследователей. Проект решает проблему ручного составления таблиц сравнения статей в Excel (экономя 15–25 часов рутины), устраняет недоверие к генеративному ИИ за счёт **100% проверяемости цитирований по DOI** и обеспечивает поддержку региональной литературы на русском и казахском языках.

Разработано в рамках курса **Technology Entrepreneurship** (Assignment 5: MVP), группа **BDA-2404** (Astana IT University).

## 🚀 Быстрый запуск

### 1. Клонирование и установка зависимостей

```bash
git clone https://github.com/bda2404/tensortext-mvp.git
cd tensortext-mvp

# Создание виртуального окружения
python -m venv .venv
# Активация:
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Linux/macOS:
source .venv/bin/activate

# Установка библиотек
pip install -r requirements.txt
```

### 2. Настройка переменных окружения (`.env`)

Создайте локальный файл `.env` (он уже добавлен в `.gitignore` и защищён от коммитов):

```env
# OpenAlex API key (опционально, для ускорения запросов и повышенных лимитов)
OPENALEX_API_KEY=

# Google Gemini API key (обязательно для извлечения PaperCards, чата и эмбеддингов)
GEMINI_API_KEY=your_gemini_api_key_here

# Модели по умолчанию
GEMINI_LLM_MODEL=gemini-3.5-flash
GEMINI_EMB_MODEL=gemini-embedding-2
```
> *API-ключи также можно в любой момент указать прямо в боковом меню (Sidebar) веб-интерфейса Streamlit.*

### 3. Запуск веб-приложения

```bash
streamlit run app.py
```
После запуска откройте в браузере: `http://localhost:8501`.  
*(Также поддерживается вызов через делегат `streamlit run app_mine.py`).*

## 🌟 Ключевые возможности

### 1. Три режима формирования корпуса публикаций
* **🔍 Поиск в OpenAlex**: Поиск по миллионам научных публикаций на английском, русском и казахском языках (RU / KZ / EN). Автоматическая нормализация разговорных тем в академические формулировки (например: *«data centers pollutes nature»* → *«data center carbon footprint and environmental impact»*) и семантическое переранжирование (Rerank) через эмбеддинги Gemini.
* **📂 Загрузка локальных PDF и BibTeX (`.bib`)**: Перетащите локальные файлы статей. Движок на базе `PyMuPDF` извлекает текст, находит **DOI** через регулярные выражения, подтягивает официальные аннотации и граф цитирований из OpenAlex, а полный текст PDF сохраняет в контексте для глубокого анализа методов.
* **🔗 Импорт по списку DOI**: Вставьте список DOI или ссылок (по одной на строку) для мгновенной пакетной подгрузки метаданных.

### 2. Защита от галлюцинаций и проверяемость (PaperCards)
* **Структурированная схема**: Каждая статья извлекается в строгий JSON:  
  `Задача` | `Метод` | `Датасет` | `Метрики` | `Ключевой результат` | `Ограничения`.
* **Правило «не указано»**: Если параметр не раскрыт в тексте публикации, модель строго возвращает `не указано`. Никаких выдуманных выборок или догадок!
* **Верификация DOI**: Каждая строка таблицы и каждая реплика в чате содержит активную гиперссылку на первоисточник вида `https://doi.org/{doi}`.
* **Оценка качества**: Встроенные кнопки 👍/👎 для каждой карточки с фиксацией в журнале обратной связи.

### 3. Интерактивный научный чат (💬 Научный диалог)
* Многошаговый академический диалог с выбранным корпусом публикаций на модели `gemini-3.5-flash` (с поддержкой `gemini-3.8-flash` и `gemini-4-argon`).
* Строгий контекстный grounding: ответы опираются только на аннотации, извлечённые карточки и фрагменты загруженных PDF.
* Каждое утверждение сопровождается цитированием в формате `[Статья N: Название](DOI)` и тегом `\cite{citekey}`.
* Возможность скачать полную стенограмму обсуждения в `.md`.

### 4. Анализ связей и выявление пробелов (Research Gaps)
* **🧩 Матрица «Метод × Датасет»**: Автоматическая нормализация терминов и кросс-табуляция, наглядно подсвечивающая «белые пятна» (где метод ещё не проверялся на данном датасете).
* **🔗 Сеть цитирований**: Анализ прямых перекрёстных ссылок между статьями, совместного цитирования (co-citations) и выявление ключевых работ.

### 5. Полный академический экспорт
* **LaTeX (`.tex`)**: Готовый к компиляции двуязычный документ со структурированной таблицей `tabularx`, преамбулой и ссылками `\cite{...}`.
* **BibTeX (`.bib`)**: Официальные записи из `doi.org` с согласованными citekeys.
* **Overleaf ZIP (`.zip`)**: Архив с `.tex` и `.bib` для мгновенного импорта в Overleaf в один клик.
* **Microsoft Word (`.docx`)**: Оформление по стандартам с полями и таблицей.
* **ГОСТ 7.0.5-2008 (`.txt`)**: Список литературы по региональному стандарту.
* **Таблица CSV (`.csv`)**: Для открытия в Excel и Google Sheets.

### 6. Менеджер сессий исследований (`tensortext_data/sessions/`)
* Автоматическое сохранение состояния на диск: история чата, поисковые запросы, выбранные статьи и извлечённые карточки не теряются при перезагрузке страницы.
* Мгновенное переключение между разными темами исследований из выпадающего списка бокового меню.

## 📸 Скриншоты и автоматизация тестирования (Playwright)

TensorText включает встроенный конвейер автоматизированного снятия скриншотов всех экранов и аналитических вкладок на базе **Playwright Chromium**:

* **По одной кнопке**: В боковом меню (Sidebar) раскройте блок *«📸 Автоматизация скриншотов (Playwright)»* и нажмите **«📷 Сделать скриншоты всех вкладок»**.
* **По одной команде в терминале**:
  ```bash
  python capture_all_screenshots.py
  ```

Скриншоты высокого разрешения сохраняются в папку `screenshots/`:

3. `03_paper_selection_grid.png` — Адаптивная двухколоночная сетка выбора статей с бейджами DOI и цитирований.

## 🏛️ Архитектура и структура репозитория

```
libro/
├── app.py                      # Основной веб-интерфейс Streamlit и порядок шагов Core Flow
├── app_mine.py                 # Точка входа-делегат (запуск app.py)
├── sources.py                  # Поиск OpenAlex, парсинг PDF (PyMuPDF), BibTeX, распознавание DOI
├── ai.py                       # LLM-экстрактор PaperCard, чат с DOI, матрица пробелов, fallback моделей
├── sessions.py                 # Менеджер сессий исследований, сохранение/восстановление истории чата
├── export.py                   # Генерация LaTeX (.tex), BibTeX (.bib), Overleaf (.zip), ГОСТ, DOCX
├── feedback.py                 # Логирование оценок доверия (1-5) и событий в feedback.csv
├── benchmark.py                # Бенчмарк на 30 RU/KZ/EN академических запросах
├── capture_all_screenshots.py  # Скрипт автоматического снятия скриншотов через Playwright
├── screenshots/                # Папка со скриншотами интерфейса высокого разрешения
├── tensortext_data/            # Локальные данные (сессии исследований, кэш карточек и эмбеддингов)
├── .env.example                # Шаблон переменных окружения (без секретов)
├── .gitignore                  # Исключение .env, .env.example, кэша и временных файлов
└── requirements.txt            # Список зависимостей Python
```
